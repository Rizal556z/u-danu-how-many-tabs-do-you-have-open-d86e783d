My entry for the [How Many Tabs Do You Have Open?](https://make.fun/competitions/u-danu-how-many-tabs-do-you-have-open-d86e783d) bounty on make.fun.

## Entry

**213**

My honest count of open browser tabs at the moment I built this entry: three windows of research, docs, half-read articles and "I'll get back to this" tabs, accumulated over weeks.

## How it works

`main.py` (pure Python standard library, no dependencies) writes the single number `213` to `/output/entry.txt` — digits only, nothing else.
